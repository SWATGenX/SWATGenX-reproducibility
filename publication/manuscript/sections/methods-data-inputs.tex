\subsection{Terrestrial, meteorological, and ancillary national inputs}
\label{sec:methods-inputs}

Beyond hydrography (Section~\ref{sec:methods-nhd}), SWAT\textsuperscript{+} project generation draws on additional U.S.\ national and regional environmental layers resolved through the same automation workflow.
Table~\ref{tab:data-master-abridged} summarizes primary datasets, providers, and roles; the full auditable inventory is in Supplementary Table~S1.
Readers will recognize PRISM \citep{Daly2008PRISM}, NLCD \citep{Dewitz2021NLCD}, gSSURGO \citep{NRCSgSSURGO}, NSRDB \citep{Sengupta2018NSRDB}, and NWIS \citep{USGSNWIS} among the recurring conterminous U.S.\ inputs.
Until submission-time pins are recorded, this manuscript avoids asserting specific product vintages in running text beyond the conservative audit notes in that inventory.

Raster elevation used with the vector hydrography is derived from NHDPlus HR staged rasters: source \texttt{elev\_cm} grids are resampled to $30~\mathrm{m}$ using bilinear resampling and reprojected to the coordinate reference system of the preprocessed stream product (\texttt{USGS\_DEM\_30m.tif} naming in implementation documentation), so that terrain derivatives remain consistent with the cleaned network.
If gridded solar or related drivers are included, product-specific horizontal resolution and vertical correction policies must match the audited configuration recorded in the dataset inventory (Table~\ref{tab:data-master-abridged}); no grid spacing is asserted here beyond that inventory.
