\subsubsection{Calibration wall-time extrapolation}
\label{sec:supp-runtime-calibration-cost}

Scenario~4 measures one filtered forward run per model (365 simulated days).
A full particle-swarm calibration repeats comparable runs while searching parameter space.
Typical watershed calibrations adjust on the order of 30--40 parameters; our production setup often uses 24--48 particles and a maximum of about 75 iterations, with early stop when the objective stagnates (often between 30 and 75 iterations).

We extrapolate each model's measured initialization and daily-loop split to a seven-year simulation window and estimate calibration wall time as
\[
\text{wall} \approx N_{\mathrm{iter}} \times \left\lceil N_{\mathrm{particles}} / N_{\mathrm{cores}} \right\rceil \times \bigl(t_{\mathrm{init}} + 7 \times t_{\mathrm{daily}}\bigr),
\]
using Scenario~4 timing and the filtered calibration NetCDF profile.
Reported ranges span 24--48 particles, 30--75 iterations, and example servers with 16, 32, or 64 cores.
RAM limits are ignored in the formula; in practice memory can cap concurrent particles even when core count is higher.
Doubling cores helps only until $N_{\mathrm{cores}} \geq N_{\mathrm{particles}}$ each iteration; further speedup requires fewer particles, fewer iterations, a shorter scored window, or the print-scope reductions in Scenarios~1--2.

\subsubsection{Production calibration optimizations beyond forward-run timing}
\label{sec:supp-runtime-optimization-stack}

The measured scenarios isolate single forward runs.
SWATGenX production calibration additionally applies:
\begin{itemize}
  \item \textbf{Gauge-limited printing} --- \texttt{print\_filter.prt} restricts daily \texttt{channel\_sd} to calibration gauges (\texttt{swift\_out=0}, \texttt{wq\_cha=0}).
  \item \textbf{NetCDF export} --- \texttt{cdfout=y} when full daily/monthly exports are required (fork extension; Table~\ref{tab:runtime-benchmark-nc-vs-txt}).
  \item \textbf{Compiler selection} --- Intel ifx \texttt{-O3 -ipo} on the reference host (Table~\ref{tab:runtime-benchmark-compiler}; Table~S2).
  \item \textbf{Shared climate I/O} --- common weather paths via \texttt{file.cio} so parallel particles reuse the same forcing files where possible.
  \item \textbf{Optional coarser landuse/soil grids} at model build to reduce HRU cardinality before calibration.
  \item \textbf{PSO pool sizing and stagnation stop} --- limit particles and terminate when the objective plateaus.
\end{itemize}
These workflow choices reduce batch overhead beyond what a one-year forward-run ladder alone captures.
