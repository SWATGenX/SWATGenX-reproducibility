For a declared VPU and list of HUC12 units, the extractor clips the preprocessed stream network, applies the one-outlet subbasin logic and lake-linkage rules of \S\ref{sec:methods-nhd}, and writes ESRI shapefiles into a SWAT\textsuperscript{+} project tree for QSWAT\textsuperscript{+}-oriented workflows \citep{QSWATplusSoftware}; every benchmark domain then runs the modified-input post-pass ($A_{\min}$ subbasin merge, outlet-topology enforcement, tiny-basin guard). Weather text inputs, SWAT\textsuperscript{+} configuration, and metadata accompanying the vector exports are part of the same generated project tree (representative file classes in Table~\ref{tab:package-manifest-abridged}; path patterns and integrity expectations in Supplementary Table~S1). Groundwater coupling (MODFLOW) and regional recharge workflows are out of scope for this hydrography-first contribution.
