Raster elevation used with the vector hydrography is derived from NHDPlus HR staged rasters: source \texttt{elev\_cm} grids are resampled to $30~\mathrm{m}$ using bilinear resampling and reprojected to the coordinate reference system of the preprocessed stream product (\texttt{USGS\_DEM\_30m.tif} naming in implementation documentation), so that terrain derivatives remain consistent with the cleaned network.
If gridded solar or related drivers are included, product-specific horizontal resolution and vertical correction policies must match the audited configuration recorded in the dataset inventory (Table~\ref{tab:data-master-abridged}); no grid spacing is asserted here beyond that inventory.
