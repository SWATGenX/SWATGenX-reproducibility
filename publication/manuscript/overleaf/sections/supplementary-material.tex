\section{Supplementary material overview}
\label{app:supplementary}

This document accompanies the main manuscript.
It provides the reproducibility file manifest (Table~S\ref{tab:repro-file-manifest}), extended Objective~5 runtime benchmark tables, and Objective~4 calibration and Morris sensitivity figures not shown in the main text.

\subsection{Reproducibility file manifest}
\label{sec:supp-repro-manifest}

Supplementary Table~S1 lists repository-relative paths for derived evaluation tables, figure-generation workflows, and supporting documentation used to produce the manuscript.
Private operational host paths, user workspaces, and credentials are excluded.
The archived software release at submission will include these materials together with a frozen git tag or equivalent DOI record (see Data Availability Statement).

Extended Objective~5 runtime benchmark tables (full compiler matrix and VTune summaries) appear in Section~S\ref{sec:supp-runtime-benchmark} (Tables~S\ref{tab:supp-runtime-compiler}--S\ref{tab:supp-runtime-vtune}).
Objective~4 calibration hydrographs and supplementary Morris figures are in Section~S\ref{sec:supp-calval-sensitivity}.
