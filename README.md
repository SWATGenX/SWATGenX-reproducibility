# SWATGenX — Reproducibility

Code, derived tables, figures, and the LaTeX manuscript sources for the SWATGenX
paper on automated NHDPlus HR → SWAT+ watershed model generation.

- Build & reproduce: see [`publication/REPRODUCIBILITY.md`](publication/REPRODUCIBILITY.md)
- File manifest: [`publication/supplement/tab-repro-file-manifest.csv`](publication/supplement/tab-repro-file-manifest.csv)
- **Executable SWAT+ model packages** for the evaluation Model IDs are downloadable from the
  SWATGenX example-models portal: https://www.swatgenx.com/example-models

Set `SWATGENX_USER_PATH` (and `SWATGENX_EXAMPLE_USER`) to point scripts at your own
downloaded SWAT+ workspace tree.
